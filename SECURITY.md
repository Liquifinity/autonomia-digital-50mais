# Segurança

Este repositório contém somente materiais públicos de apresentação.

Não estão publicados:

- código da área do aluno ou da administração;
- integrações de pagamento;
- credenciais ou variáveis de ambiente;
- dados pessoais, comerciais ou operacionais;
- materiais internos do curso.

Se você identificar um problema de segurança no site, não abra uma issue pública com detalhes exploráveis. Entre em contato pelos canais oficiais do projeto para permitir análise responsável.
